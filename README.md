# My First Agent

Primera práctica creando un agente básico con Kit ADK de manera local.
Se despliega de manera local utilizando la siguiente estructura:

- [__pyche__/__init__.cpython-312.pyc](https://github.com/MatiasMaxRodriguez/MyFirstAgent/blob/main/__pycache__/__init__.cpython-312.pyc)
- [__pyche__/agent.cpython-312.pyc](https://github.com/MatiasMaxRodriguez/MyFirstAgent/blob/main/__pycache__/agent.cpython-312.pyc)
- [__init__.py](https://github.com/MatiasMaxRodriguez/MyFirstAgent/blob/main/__init__.py)
- [agent.py](https://github.com/MatiasMaxRodriguez/MyFirstAgent/blob/main/agent.py)

## Tecnologías utilizadas:

[Agent Development Kit (ADK)](https://adk.dev/),
[Python](https://www.python.org/)
